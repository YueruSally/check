# China–US Multimodal Transport Paper

## 项目说明

本目录用于从头开展有关中国与美国多式联运的论文研究与写作，与仓库中的既有工作分开管理。

## 暂定研究主题

中国与美国多式联运体系的比较研究：基础设施、组织模式、政策环境、运输效率与低碳转型。

## 初步工作结构

1. 明确研究问题与比较框架
2. 开展中英文文献综述
3. 收集中国与美国的政策、运输网络及运营数据
4. 设计研究方法与案例选择
5. 完成论文提纲、初稿、修改稿与终稿
6. 整理图表、参考文献和补充材料

## 建议目录

后续按需要建立：

- `manuscript/`：论文正文
- `literature/`：文献笔记
- `data/`：数据与来源说明
- `analysis/`：分析代码和结果
- `figures/`：图表
- `references/`：参考文献
- `notes/`：研究日志与待办事项
